# 工作摘要 — 粒子形状分类全息图生成器

> 日期：2026-06-11　|　项目：数字全息仿真 — 圆形/不规则粒子分类

---

## 背景与目标

MATLAB 重建管线已具备仿真模式适配（见[[工作摘要_20260611]]），能从全息图重建粒子场。下一步需求是**区分圆形粒子和不规则粒子**。

实验端面临两个困难：
- 找不到合适的不规则粒子来实拍（PTFE 粉末重建效果差，MIP 上几乎看不到有效信号）
- 需要带标签的训练数据来训练分类器

因此需要一套数值仿真管线，能生成包含**圆形 + 不规则粒子**的合成全息图，每条数据自带形状标签和几何真值。

### 目标参数

| 参数 | 值 |
|---|---|
| 图像尺寸 | 1024×1024 px |
| 像元尺寸 | 3.45 µm |
| 波长 | 638 nm |
| 深度范围 | 20–35 mm |
| 粒子半径 | 50–100 µm |
| 每张粒子数 | 20（圆形 + 不规则各约一半） |
| 不规则类型 | 聚合球体（PTFE-like）+ 凸多面体（冰晶碎片-like） |

## 物理模型选型

对 50–100 µm 半径粒子在 638 nm 波长下的散射问题（尺寸参数 x ≈ 500–1000），评估了以下方案：

| 方法 | 结论 | 理由 |
|---|---|---|
| **FDTD** | ❌ 直接排除 | 网格需 λ/20 ≈ 32 nm，单粒子 200 µm 域需 ~2440 亿网格点 |
| **DDA（离散偶极子）** | ❌ 不现实 | 偶极数 ∝ (r/λ)³，x≈500 需 10⁶–10⁷ 偶极子/粒子，20 粒子不可行 |
| **Mie 理论** | ⚠️ 仅限圆形 | 级数展开，毫秒级精确解，但不适用于不规则粒子 |
| **T-Matrix** | ⚠️ 部分适用 | 可处理椭球/柱体等轻度非球形，但对任意形状支持有限 |
| **薄相位屏 + 角谱传播** | ✅ **选定方案** | 物理合理 + 计算可行 + 与现有 MATLAB 管线兼容 |

### 选定模型

\[
t(x,y) = A(x,y) \cdot \exp(i \cdot k \cdot \Delta n \cdot h(x,y))
\]

\[
U_{scatter} = \text{AngularSpectrum}(t-1, z_i)
\]

\[
I = |1 - \sum U_{scatter,i}|^2
\]

其中：
- \(h(x,y)\) — 粒子沿光轴方向的厚度
- \(A(x,y)\) — 振幅衰减（0~1），含边缘高斯过渡
- \(\Delta n = n_{particle} - n_{medium}\) — 折射率对比度

### 模型定位（汇报用）

> 本模型不是高保真电磁散射仿真，而是面向形态分类和重建链路验证的近似前向模型。在尺寸参数 x ≈ 500–1000 条件下，薄屏模型主要保留投影厚度、相位延迟、遮挡和边缘衍射信息。薄屏成立性判据 z < d²/λ 在 d ≈ 10 µm 时给出约 157 µm 容限，而粒子典型厚度约 200 µm，属于边缘成立——因此模型能捕捉粒子形态对重建投影的主要影响，但不对衍射环精细结构做严格定量预测。

## 粒子形状生成

### 圆形粒子 — `SphereShape`

```python
h(x,y) = 2 * sqrt(R² - (x-x₀)² - (y-y₀)²)   # 球体厚度公式
```

解析解，不需要体素化，计算最快。

### 不规则类型 1：聚合球体 — `AggregateShape`

模拟 PTFE 粉末团聚体。N 个随机大小子球体松散堆叠：

- 子球体数量：5–15 个
- 子球体半径：目标半径的 25–60%
- 分布偏向外壳区域（避免形成近球体）
- 连通性要求低（松散搭接即算连接）

特点：圆滑边缘、无棱角、弥散衍射环。

### 不规则类型 2：凸多面体 — `PolyhedronShape`

模拟冰晶碎片 / 矿物颗粒。采用**星形点云 + ConvexHull** 算法：

```
对 N 个均匀分布的方向向量，随机分配三类半径：

  常规点 (~65%):  r = R × uniform(1-jitter, 1+jitter)
  内缩点 (~20%):  r = R × uniform(0.25, 0.65)   → 形成大平面
  突刺点 (~12%):  r = R × uniform(1.6, 2.5)     → 形成尖锐顶点

→ ConvexHull → 棱角分明、大小面掺杂的多面体
```

三级破碎度预设：

| 预设 | jitter | spike | indent | vertices | 效果 |
|---|---|---|---|---|---|
| `mild` | 0.25 | 0.06 | 0.10 | 12–22 | 轻微不规则 |
| `medium` | 0.40 | 0.12 | 0.20 | 15–35 | 中等破碎（默认） |
| `severe` | 0.55 | 0.20 | 0.30 | 20–45 | 强破碎、棱角分明 |

三种粒子类型走**同一物理管线**，差异仅来自 h(x,y) 形态。分类器学到的是形态差异，不是模型差异。

## 工程实现

### 关键性能优化

| 优化项 | 改前 | 改后 | 效果 |
|---|---|---|---|
| **体素化内存** | 3D meshgrid（420³×3 float64 ≈ 1.8 GB/粒子） | 逐层 2D 切片（~300 KB/粒子） | 内存降低 ~5000 倍 |
| **体素分辨率** | 固定 0.5 µm | 自适应 `max(1.5, r/50)` µm | 体素数从 420³ → ~80³ |
| **全息图合成速度** | 61 秒/张 | **3 秒/张** | 20 倍加速 |
| **边缘模糊** | σ=1.5 px（适应 2.2 µm 像元） | σ=0.8 px（适应 3.45 µm 像元） | 消除圆粒子"圆角正方形"现象 |
| **相位单位 bug** | `k * dn * h_um`（h_um 为 µm） | `k * dn * (h_um * 1e-6)` | 🔴 修复相位放大 10⁶ 倍 |

### 超采样抗锯齿

厚度场在 3× 子像素分辨率计算后平均降采样，消除圆形粒子在离散像素网格上的锯齿/圆角正方形伪影。

## 使用方法

### GUI

```bash
cd functionme/仿真图像生成
python generate_hologram_gui.py
```

- 顶部下拉框切换「标准仿真」/「形状分类」
- 形状分类模式：设置粒子数、粒径、折射率、破碎度等 → 点击生成
- 自动前缀编号，不会覆盖已有数据

### 命令行

```bash
# 单张生成（默认参数）
python generate_hologram_shape_classifier.py -o ./output/0001 -s 42

# 强破碎不规则粒子
python generate_hologram_shape_classifier.py --fragmentation severe -o ./test

# 精细控制多面体参数
python generate_hologram_shape_classifier.py \
    --poly-radial-jitter 0.5 --poly-spike-fraction 0.18 \
    --poly-indent-fraction 0.25 -o ./test

# 批量生成 50 张训练集（约 2.5 分钟）
python batch_generate_training_set.py --num 50 -o ./training_set
```

### 输出格式

```
0001/
├── 0001_hologram.bmp          # 8-bit 全息图（可视化用）
├── 0001_hologram.mat          # float64 精确全息图（MATLAB load 直接读取）
├── 0001_object_reference.bmp  # 物面投影真值图
├── 0001_ground_truth.csv      # 粒子真值表
│   ├── particle_id            # 粒子编号
│   ├── shape_type             # sphere / aggregate / polyhedron
│   ├── x_pixel, y_pixel       # 0-indexed 坐标
│   ├── x_pixel_matlab         # 1-indexed 坐标（MATLAB 直接用）
│   ├── z_position_m, z_position_mm
│   ├── equivalent_diameter_um # 等效球直径
│   ├── volume_um3             # 真实体积
│   └── shape_params           # 形状特定参数
└── 0001_metadata.json         # 仿真参数记录
```
