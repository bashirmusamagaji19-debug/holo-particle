# 工作摘要 — 仿真与MATLAB重建对齐

> 日期：2026-06-11　|　项目：数字全息仿真与重建

---

## 背景

项目包含两条管线：
- **Python 端**（`仿真图像生成/`）：生成合成数字全息图及粒子真值
- **MATLAB 端**（`MATLAB版/`）：从全息图反向重建粒子场，做粒径统计

经详细代码审查发现，MATLAB 重建管线已为**特定实验装置**高度特化，导致对 Python 生成的合成全息图完全无法正确重建。

---

## 发现的问题

| 编号 | 问题 | 严重度 | 位置 |
|---|---|---|---|
| P1 | 硬编码 `(diams>=20)&(diams<=35)` 粒径筛选 | 🔴 致命 | `Fresnel_reconstructFastStats.m:384` |
| P2 | `_to_uint8` 非线性编码 + MATLAB 端 uint8 直当复数场 | 🔴 严重 | Python `_to_uint8()` + MATLAB `onReconstruct` |
| P3 | `I = max(Amp) - Amp` 对比度反转假设不匹配 | 🔴 严重 | `Fresnel_reconstructFastStats.m:95` |
| P4 | 角谱（生成）vs 菲涅尔（重建）传播模型差异 | 🟡 中等 | 双端 |
| P5 | Born 近似仿真 vs 实验全息图特征差异 | 🟡 中等 | 双端 |
| P6 | 0-indexed vs 1-indexed 坐标系统 | 🟢 轻微 | 对比真值时需注意 |

详细分析见 `仿真与MATLAB重建对齐问题.md`。

## 实施的修改

### 设计思路

在 MATLAB GUI 新增 **「Simulation mode」复选框**，勾选后自动切换到仿真适配流程，不勾选时 100% 保持原有实验流程不变。

### 改动的文件

#### 1. `MATLAB版/AS_preprocessHologram.m`
- 新增第三个参数 `options`，字段 `isSimulation`
- 仿真模式：`double(img)/255.0` 归一化 → 减背景 → `- mean()` 去直流
- 实验模式：行为不变

#### 2. `MATLAB版/Fresnel_reconstructFastStats.m`
- `iFillDefaultParams`：仿真/实验两套默认值
  - 仿真：`minDiamPx=3, maxDiamPx=200, minCircularity=0.3, invertContrast=false, watershedHmin=0.3`
  - 实验：`minDiamPx=20, maxDiamPx=35, minCircularity=0.6, invertContrast=true, watershedHmin=0.8`
- `iDetectCandidates`：硬编码值 → `params.xxx` 字段
- GPU/CPU 核心 + patch 收集函数：`if invertContrast` 条件分支

#### 3. `MATLAB版/VolumeGUI_AngularSpectrum.m`
- 左栏加「Simulation mode」复选框（GPU 复选框上方）
- `onReconstruct` 回调：读复选框值 → 传入 `AS_preprocessHologram` → 传入 `fastStatsParams.simulationMode`

### 数据流

```
☑ Simulation mode 勾选
        │
        ▼
AS_preprocessHologram(dataImg, bgImg, {isSimulation: true})
  → /255 → [0,1] → 减背景 → -mean → 零均值全息图
        │
        ▼
Fresnel_reconstructFastStats(holoPre, ..., {simulationMode: true, ...})
  → 放宽粒径筛选 (3-200px)
  → 不放宽圆度 (0.3)
  → 不反转对比度 (I = Amp)
  → 降低分水岭深度 (0.3)
```

## 使用说明

1. 在 Python 端生成仿真全息图（BMP + CSV）
2. 打开 MATLAB，运行 `VolumeGUI_AngularSpectrum`
3. **勾选左栏「Simulation mode」复选框**
4. 加载仿真全息图 BMP
5. 根据仿真参数调整 UI 中的波长、像元尺寸、Z 范围、Z 步长
6. 点击重建按钮

> ⚠️ 勾选 Simulation mode 后会自动做 `/255` 归一化和 DC 去除，因此**不要**在 MATLAB 外部手动预处理 BMP。
