## 1. 背景与目标

MATLAB 重建管线已具备仿真模式适配。下一步需求是**区分圆形粒子和不规则粒子**（冰晶碎片、PTFE 团聚体等）。实验端找不到合适的不规则粒子实拍，因此需要数值仿真生成带标签的训练数据。

目标参数：
- 图像：1024×1024 px，3.45 µm/pixel
- 波长：638 nm，深度 20–35 mm
- 粒子半径：50–100 µm，每张 20 个（圆形 + 不规则混合）
- 输出：BMP + .mat（浮点）+ CSV 真值（含 shape_type）

---

## 2. 物理模型

经过对 FDTD、DDA、Mie、T-Matrix 等方案的评估，选定**复透射率薄屏 + 角谱传播**：

```
t(x,y) = A(x,y) · exp(i · k · Δn · h(x,y))
U_scatter = AngularSpectrum(t-1, z_i)
I = |1 - ΣU_scatter|²
```

- h(x,y)：粒子沿光轴方向的厚度投影
- A(x,y)：振幅衰减（0~1），边缘高斯过渡
- Δn = n_particle − n_medium

> 定位：不是高保真电磁散射仿真，而是面向形态分类和重建链路验证的近似前向模型。尺寸参数 x≈500–1000，薄屏成立性边缘成立。

---

## 3. 三种粒子形态

| 类型 | class | 生成算法 |
|---|---|---|
| 圆形 | `SphereShape` | 球体解析公式 h=2√(R²−d²) |
| 聚合球体 | `AggregateShape` | 5–15 个随机子球体表面偏置堆叠 → 体素化 |
| 凸多面体碎片 | `PolyhedronShape` | 星形点云 × 3 类半径 → ConvexHull → 多碎片并集 → 体素化 |

三种类型走同一物理管线，差异仅来自形态。

## 4. 关键 Bug 修复

### 4.1 相位单位错误 🔴

```python
# 改前（错误）：h 为 µm，直接乘 k (1/m)，相位放大 10⁶ 倍
phase = k * dn * h_img

# 改后：转为米
phase = k * dn * (h_img * 1e-6)
```

### 4.2 复数降采样顺序错误 🔴

```python
# 改前（错误）：先对实数厚度 h 平均，再算 exp(iφ)
# 当像素内相位变化 >> 2π 时，结果随机
h_img = h_fine.reshape(...).mean()
phase = k * dn * (h_img * 1e-6)
t_local = A * exp(1j * phase)

# 改后：在细网格算完复数，再对复数平均（相干平均）
phase_fine = k * dn * (h_fine * 1e-6)
t_fine = exp(1j * phase_fine)
t_img = t_fine.reshape(...).mean()   # 复数平均
t_local = A * t_img
```

物理效果：子像素相位振荡在复平面上互抵消，|t_avg|≈0（均匀暗区），MIP 亮斑干净。

### 4.3 体素化内存爆炸 🔴

```python
# 改前：3D meshgrid 对 100µm 粒径产生 420³×3×8B ≈ 1.8GB/粒子
X, Y, Z = np.meshgrid(voxel_centers, voxel_centers, voxel_centers)

# 改后：逐层 2D 切片，内存 O(N²) ≈ 300KB/粒子
X2D, Y2D = np.meshgrid(voxel_centers, voxel_centers)  # 复用
for z in voxel_centers:  # 逐层
    occupied_2d = test_halfspaces(X2D, Y2D, z)
```

+ 自适应体素：`voxel_um = max(1.5, radius/50)`，100µm 粒子用 2µm 体素

性能：1024×1024 全息图生成从 61 秒 → **3 秒**。

## 5. 凸多面体形态演进

| 版本 | 算法 | 问题 |
|---|---|---|
| v1 | 球面均匀点 → ConvexHull | 太规则，近球形 |
| v2 | 星形点云（三类半径）→ ConvexHull | 棱角分明，但仍是凸集 |
| v3 | 凸包 + 半空间切角（交集） | **交集永远凸**，无凹口 |
| v4（最终） | 2–4 个独立凸碎片 → **布尔并集** | ✅ 真正非凸：凹角、缺口、锯齿 |

参数：`num_fragments`=2–4，`fragment_overlap`=0.3–0.7。三级预设：mild / medium / severe。

## 6. 默认光学参数调整

为提高 MIP 对比度和亮斑均匀性，降低相位过强程度：

| 参数 | 旧默认 | 新默认 | 理由 |
|---|---|---|---|
| n_particle | 1.5 | **1.38** | Δn≈0.38，减相位绕转 |
| attenuation | 0.6 | **0.30** | 振幅对比度从 0.4→0.7 |
| roughness | 0.03 | **0** | 去内部振幅扰动 |
| edge_sigma_px | 1.5 | **0.8** | 适应 3.45µm 大像素 |
| 像元尺寸 | 2.2 µm | **3.45 µm** | 匹配实际相机 |

## 7. MATLAB 检测管线改动

### 7.1 候选检测 — 双阈值 + 条件分水岭

```matlab
% 仿真的检测策略（替换单硬阈值 + watershed）
highLevel = 0.65     → 确认亮核，排除噪声
lowLevel  = 0.26     → 保留弱连接和突起

对每个低阈值连通域：
  1 个亮核        → 保持整体（单粒子）
  N 个亮核        → 检查：
    - 间距 < minSepPx  → 不切（不规则粒子内部亮斑）
    - 面积太小        → 不切
    - 碎片太小        → 撤销切分
    - 通过            → marker watershed 分离
```

保护条件：
- `minSepPx = max(15, minDiamPx × 1.2)`
- 切割后任一片段 `EquivDiameter < minDiamPx` → 回退保持整体

### 7.2 粒径计算 — Heywood 等效直径

仿真模式用 MIP 投影面积计算：

```
D_eq = 2 × sqrt(Area / π)           (Heywood 直径, px)
V = π × D_eq³ / 6                    (球形近似体积)
```

统一圆形/不规则粒子的尺寸表征标准（HACPI 云粒子规范）。

### 7.3 不规则粒子入有效统计

仿真模式 `minPeakRatio` 上限 1.05（实验模式 1.15）——不规则粒子峰值比天然低。

### 7.4 GUI 改动

- **概览图**：画 `candidateRoiBoxes`（BoundingBox+margin），不用等效直径方框
- **颜色编码**（仿真模式）：圆形=绿色（circularity≥0.55），不规则=橙色
- **直径过滤**：UI 新增"最小有效粒径(µm)"，低于此值不画框
- **诊断窗口**：重建后自动弹出 2×3 子图（MIP / 低阈值 / 高阈值 / 最终Mask / 叠加 / ROI框）
- **预处理面板**新增"最小有效粒径(µm)"输入框

### 7.5 预存 Bug 修复

- `pdist` 替换为手动距离矩阵（无 Statistics Toolbox 依赖）
- CPU 路径 `argmaxZMap` 赋值 mask 索引修复（与 GPU 路径对齐）

## 9. 使用方式

### Python 端生成

```bash
# GUI
python generate_hologram_gui.py

# CLI 单张
python generate_hologram_shape_classifier.py -o ./output/0001 --fragmentation medium

# 批量训练集
python batch_generate_training_set.py --num 50 -o ./training_set
```

### MATLAB 端重建

1. 启动 `VolumeGUI_AngularSpectrum`
2. 勾选 **Simulation mode**
3. 加载生成的 BMP 全息图
4. 调整波长/像元/Z 范围参数
5. 点击重建
6. 查看弹出诊断窗口 + MIP 概览（绿色=圆形，橙色=不规则）
