## 1. 两条链路的共同框架

无论仿真还是实验模式，都走同一套函数调用链：

```
VolumeGUI_AngularSpectrum → onReconstruct()
  ├─ [1] AS_preprocessHologram()        ← 预处理（双模式分支点 ①）
  ├─ [2] Fresnel_reconstructFastStats()  ← 核心重建（双模式分支点 ②③④⑤）
  │      ├─ iFastStatsGpuCore / iFastStatsCpuCore
  │      │    ├─ iFrequencyGrid()       ← 频域坐标网格
  │      │    ├─ fft2(holo)             ← 全息图 FFT
  │      │    ├─ 逐批 MIP 累积循环        ← 反向传播 + 振幅 + MIP
  │      │    └─ GPU→CPU 回传
  │      ├─ iDetectCandidates()         ← 候选粒子检测（双模式分支点）
  │      ├─ iEstimateFocusFromMaps()    ← 焦面粗估
  │      ├─ iCollectBestPatchesCpu/Gpu()← 收集最佳焦面 patch
  │      └─ iFinalizeSummaryFromMaps()  ← 粒径精测 + 有效性判定
  │           ├─ AS_refineMeasurementROI()
  │           └─ iEstimateFocusDiameterFromPatch()
  └─ [3] onSimpleStatsV2()             ← 统计计算与展示
```

两条链路的**差异完全由 `simulationMode` 布尔值控制**，在以下 5 个分支点做出不同选择：

| 分支点 | 位置 | 控制方式 |
|---|---|---|
| ① 预处理 | `onReconstruct` → `AS_preprocessHologram` | `options.isSimulation` |
| ② 对比度反转 | `iFastStatsGpuCore/CpuCore` MIP 循环 | `params.invertContrast` |
| ③ 候选粒径筛选 | `iDetectCandidates` | `params.minDiamPx / maxDiamPx` |
| ④ 圆度筛选 | `iDetectCandidates` | `params.minCircularity` |
| ⑤ 分水岭深度 | `iDetectCandidates` | `params.watershedHmin` |

## 2. 仿真链路（Simulation mode ☑）

仿真链路处理的是 Python `generate_hologram_matlab_validation_new.py` 生成的合成全息图。这些全息图基于 **Born 近似**（单次散射），以 8-bit BMP 格式保存，粒子在重建振幅中表现为亮区。

### 2.1 阶段一：预处理

**函数**：`AS_preprocessHologram(dataImg, bgImg, {isSimulation: true})`

```
输入：uint8 BMP（imread 读入，值域 [0, 255]）
       ↓
步骤1：holo = double(img) / 255.0        → 恢复到 [0, 1] 浮点域
       ↓
步骤2：若提供了背景图 bgImg：
         bg = double(bgImg) / 255.0
         尺寸对齐（必要时 imresize）
         holo = holo - bg               → 扣除背景
       ↓
步骤3：holo = holo - mean(holo(:))       → 去除直流分量（DC）
       ↓
输出：零均值全息图，值域约 [-0.5, 0.5]
```

**为什么要 /255？**

Python 端 `_to_uint8()` 函数将浮点全息图做了非线性压缩：

```python
clipped = clamp(image, P0.1, P99.9)      # 截断极端值
normalized = (clipped - min) / (max - min) # 线性拉伸到 [0,1]
uint8(normalized * 255)                   # 量化到 8-bit
```

如果不 `/255` 恢复到 [0,1]，MATLAB 会把 uint8 值（0-255）直接当物理强度用，数量级完全错误。

**为什么要 -mean()？**

BMP 的全息图 DC 分量被量化到约 0.5（归一化后），对应 FFT 零频的巨大尖峰。减均值消除此 DC，避免重建背景过强、淹没粒子信号。

---

### 2.2 阶段二：菲涅尔反向传播 + MIP 累积

**函数**：`iFastStatsGpuCore` 或 `iFastStatsCpuCore`（取决于 GPU 可用性）

#### 2.2.1 频域网格生成

```matlab
fx = ifftshift( -⌊nx/2⌋ : ⌈nx/2⌉-1 ) / (nx · pixel)
fy = ifftshift( -⌊ny/2⌋ : ⌈ny/2⌉-1 ) / (ny · pixel)
[FX, FY] = meshgrid(fx, fy)
```

- GPU 路径：`double` 型（保证传递函数相位精度）
- CPU 路径：`double` 型

#### 2.2.2 全息图 FFT

```matlab
U0f = fft2(holo)    % GPU: gpuArray(single); CPU: single
```

#### 2.2.3 传递函数（菲涅尔傍轴近似）

```
phaseBase = -iπλ · (FX² + FY²)      % 菲涅尔衍射相位核
k_offset  = 2π / λ                   % 波数偏移

H(z) = exp(i · k_offset · z + phaseBase · z)
     = exp(i · k · z) · exp(-iπλz · (fx² + fy²))
```

这是菲涅尔衍射的频域传递函数。与角谱法 `exp(i·k·z·√(1−λ²(fx²+fy²)))` 相比，它是**傍轴近似**，假设观测距离远大于波长、衍射角小。

#### 2.2.4 逐批反向传播 + MIP 累积（★ 关键分支点 ②）

```matlab
for s = 1:batchSize:nz           % 按显存/内存容量分批
    zBatch = zVec(s:s+batchSize-1)
    H = exp(1i * k_offset * zBatch + phaseBase .* zBatch)
    Amp = abs(ifft2(U0f .* single(H)))    % 反向传播 → 振幅

    % ★ 仿真模式：invertContrast = false
    I = Amp                                % 直接使用振幅！粒子是亮区

    sum2D  = sum2D + sum(I, 3)             % 逐像素 z 向求和
    [batchMax, localArgmax] = max(I, 3)    % 当前批次最大值
    updateMask = batchMax > mip2D
    mip2D(updateMask) = batchMax           % 更新全局 MIP
    argmaxZMap(updateMask) = 对应z层号     % 更新最大值位置
end
```

**为什么仿真模式不反转？**

实验全息图中，粒子在重建振幅中表现为**暗区**（因为粒子散射的光与参考光干涉产生暗环），需要用 `max(Amp) - Amp` 反转让粒子变亮。但 Python 的 Born 近似仿真中，粒子直接就是正向散射源，在重建振幅中已经是**亮区**，不需要也不应该反转——反转会把粒子变成暗区、背景变成亮区。

#### 2.2.5 GPU→CPU 回传

```matlab
mip2D      = gather(mipG)      % 沿 z 的最大强度投影
argmaxZMap = gather(argmaxZG)  % 每个像素最大值所在的 z 层号
mean2D     = gather(sumG / nz) % 沿 z 的平均强度
```

#### 2.2.6 批大小管理

- **GPU**：每页 ~36 字节/像素，取可用显存的 65% 减去 0.4GB 安全缓冲，上限 64 层
- **CPU**：固定 1.8GB 上限，按每页 36 字节折算
- 显存不足时自动回退 CPU

### 2.3 阶段三：候选粒子检测

**函数**：`iDetectCandidates(mip2D, params)`，其中 params 携带仿真参数。

#### 2.3.1 归一化

```matlab
img2D = AS_normalizeImage(mip2D)
% = (mip2D - min(mip2D)) / (max(mip2D) - min(mip2D))
% 线性映射到 [0, 1]
```

#### 2.3.2 二值化

```matlab
level = xyThreshold              % 默认 0.70
bw = imbinarize(img2D, level)    % 全局阈值二值化
bw = bwareaopen(bw, 3)           % 移除 < 3 像素的小区域
bw = imfill(bw, 'holes')         % 填充孔洞
```

阈值 0.70 意味着 MIP 上灰度值处于前 30% 的像素被标记为候选区域。

#### 2.3.3 分水岭分割（★ 分支点 ⑤）

```matlab
% 仿真模式：watershedHmin = 0.3
D = -bwdist(~bw)                    % 距离变换（取负，粒子内部为谷）
mask = imextendedmin(D, 0.3)        % ★ H-minima 变换，深度 0.3
D2 = imimposemin(D, mask)           % 强制局部极小值
L_watershed = watershed(D2)         % 分水岭变换
bw(L_watershed == 0) = 0            % 脊线置零，分离粘连粒子
```

**`imextendedmin(D, 0.3)` 的含义**：

在距离变换的"地形"中，只保留深度 ≥ 0.3 的局部极小值。仿真 MIP 噪声低、对比度高，用较低的 0.3 可以检测到更浅的凹陷，从而分离靠得更近的粒子。这与实验模式（0.8）差异显著。

#### 2.3.4 启发式筛选（★ 分支点 ③④）

```matlab
all_diams     = [stats_raw.EquivDiameter]   % 等效直径 (px)
all_areas     = [stats_raw.Area]            % 面积 (px²)
all_perimeters = [stats_raw.Perimeter]      % 周长 (px)

circularity = (4π × Area) / (Perimeter²)    % 圆度：完美圆 = 1

% 仿真模式参数
keep = (diams >= 3)   & (diams <= 200)      % ★ 粒径 3-200px
     & (circularity > 0.3)                   % ★ 圆度 > 0.3
```

**粒径范围 3-200px 的物理含义**（2.2µm/px 像元）：

| | 最小 (3px) | 最大 (200px) |
|---|---|---|
| 像素 | 3 px | 200 px |
| 物理尺寸 | ~6.6 µm | ~440 µm |

这个范围覆盖了仿真数据集 0001（10-20µm）到 0011（100µm）的所有粒子。

**圆度 0.3**：允许相当不规则的形状。仿真数据中，粒子在 MIP 上的投影受 Born 近似和频域截断影响，不一定呈完美圆形——但也不能太离谱（0.3 已排除明显是噪声细长条的假阳性）。

#### 2.3.5 自适应 ROI 构建

对每个通过筛选的候选粒子，调用 `AS_buildAdaptiveROI` 构建搜索窗口：

```matlab
初始半径 = max(roiMinRadius, bbox半径, equivDiam×roiScale, searchMinRadiusUm/pix_um)
         = max(15, bbox半径, equivalentDiam×0.5, 30µm / 2.2µm)
         = max(15, bbox半径, 0.5×等效直径, ~13.6)

while 边缘能量 > 0.20 AND 半径 < 最大半径:
    radius = ceil(radius × 1.25)
    重新裁剪 → 计算 edgeEnergy

边缘能量 = (max(四边像素值) - bg) / (max(patch) - bg + eps)
```

**边缘能量**衡量粒子信号是否溢出当前窗口：如果边缘像素还很亮（接近内部峰值），说明窗口太小，需要继续扩大。

### 2.4 阶段四：焦面定位与 Patch 收集

#### 2.4.1 焦面粗估 — `iEstimateFocusFromMaps`

对每个候选粒子的 ROI 区域：

```matlab
zPatch   = argmaxZMap(ROI区域)     % 每个像素在哪个 z 层达到最大值
wPatch   = mip2D(ROI区域)         % 该像素的 MIP 强度（作为投票权重）

对每个唯一的 z 值：
  weight(z) = Σ wPatch(zPatch == z)  % 加权投票

bestZ = argmax_z weight(z)           % 得票最多的 z 层 = 最佳焦面
```

同时计算：

```matlab
peakRatio = mean(wPatch) / max(mean(mean2D(ROI区域)), eps)
```

`peakRatio` 是 ROI 内 MIP 均值与整体均值之比，用作粒子信噪比的代理指标。值越大，粒子越显著。

#### 2.4.2 收集最佳焦面 Patch — `iCollectBestPatchesCpu/Gpu`

对每个候选粒子，在其最佳焦面 z 上重新反向传播，取出局部 patch：

```matlab
对每个唯一的 bestZ：
  H = exp(i·k·z + phaseBase·z)
  Amp = abs(ifft2(U0f · single(H)))
  I = Amp                             % 仿真：不反转

  对每个最佳焦面在 z 的候选粒子 n：
    bestPatches{n} = I(c.y1:c.y2, c.x1:c.x2)  % 裁剪 ROI 区域
```

此步骤避免了保存完整 3D 体数据——只保留每个粒子在最佳焦面上的局部 patch（通常几十到上百像素见方），内存开销极小。

### 2.5 阶段五：粒径精测与有效性判定

**函数**：`iFinalizeSummaryFromMaps`

#### 2.5.1 测量 ROI 细化 — `AS_refineMeasurementROI`

在焦面 patch 上做精细的能量重定位：

```matlab
步骤1：从 focusSlice 裁出搜索区域
步骤2：用四边中位数估计背景电平 bgLevel
步骤3：energyMap = max(patch - bgLevel, 0)     % 非负能量图
步骤4：refinedCenter = 能量图质心坐标            % 比 WeightedCentroid 更准
步骤5：按像素到质心的距离升序排列
       累计能量达到 92% 时的距离 = measureRadius  % 测量半径
步骤6：输出紧凑的 measureBox（全局 + 局部坐标）
```

**92% 能量分数** 的含义：从质心向外扩展，当圈入的能量达到总能量的 92% 时停止。这个值排除了焦面外围的渐晕/噪声，同时保留了粒子的主能量区域。

#### 2.5.2 焦面粒径精测 — `iEstimateFocusDiameterFromPatch`

```matlab
步骤1：AS_normalizeImage(measurePatch)           → [0,1]
步骤2：localLevel = clamp(Otsu阈值, 0.35, 0.85)  → 自适应二值化阈值
       （若 graythesh 不可用，用 xyThreshold 推算）
步骤3：bwFocus = imbinarize → bwareaopen(1) → imfill('holes')
步骤4：bwconncomp → regionprops → EquivDiameter
步骤5：找到包含原候选中心点的连通域
步骤6：若找不到，选离中心最近的连通域
步骤7：输出 EquivDiameter（等效圆直径，像素单位）
```

**为什么要 clamp Otsu 阈值到 [0.35, 0.85]？**

Otsu 方法假设图像有双峰直方图，但焦面 patch 中粒子只占小部分区域。如果粒子很小，Otsu 可能给出过低的阈值（导致把噪声标为目标）或过高（漏掉粒子）。clamp 到 0.35-0.85 确保阈值在合理范围内。

#### 2.5.3 有效性判定

```matlab
isAwayFromEdge = (bestZ > edgeMargin) & (bestZ <= nz - edgeMargin)
               = (bestZ > 2) & (bestZ <= nz - 2)

valid = isAwayFromEdge AND (peakRatio >= minPeakRatio)
                          AND (peakRatio >= 1.15)
```

两个条件：
1. **远离 Z 边界**：距 Z 范围两端至少 2 层。Z 边界附近的重建存在截断伪影，粒子定位不可靠。
2. **信噪比足够**：MIP 峰值 / 均值 ≥ 1.15。低于此值说明该"粒子"的对比度太弱，可能是噪声波动。

只有通过两项检验的候选才计入最终统计。

### 2.6 阶段六：统计汇总与展示

**函数**：`onSimpleStatsV2`（GUI 回调）

```matlab
diamsUm = diamsPx × pix_um              % 粒径：像素 → 微米

% 体积中位径 (MVD)
diamSorted = sort(diamsUm)
volWeights = diamSorted³                % 体积权重 ∝ d³
cumFrac    = cumsum(volWeights) / sum(volWeights)
MVD        = interp(cumFrac, diamSorted, 0.5)   % 累计体积 50% 的粒径

% Sauter 平均径 D[3,2]（体积/表面积平均）
D32 = Σ(d³) / Σ(d²)

% 数浓度（个/mL）
reconVolume = rows × cols × pix_um² × zSpanUm   % 重建体积 (µm³)
numConcPerMl = particleCount × 1e12 / reconVolume   % 换算到 mL

% 输出
StatsResult = struct(
    coordsUm, diamsUm, coordsPx, diamsPx, pixUm, zVecUm,
    count, meanDiamUm, mvdUm, D32, numConcPerMl, ...
)
```

结果在 GUI 右栏展示：统计摘要标签、粒径分布直方图、粒子结果表格。

## 3. 实验链路（Simulation mode ☐）

实验链路处理的是真实数字全息实验采集的全息图。这些全息图通常也是 8-bit 图像，但物理特征与仿真全息图有本质差异。

### 3.1 预处理差异

**函数**：`AS_preprocessHologram(dataImg, bgImg, {isSimulation: false})`

```
输入：uint8 实验全息图
       ↓
步骤1：holo = double(img)               → 转 double，但不做 /255
       ↓                                   值域保持 [0, 255]
步骤2：若提供了背景图 bgImg：
         bg = double(bgImg)             → 也不做 /255
         尺寸对齐
         holo = holo - bg               → 扣除背景
       ↓
步骤3：不减去均值！                       → 保留 DC 分量
       ↓
输出：值域约 [0, 255] 或减背景后约 [-255, 255]
```

**为什么不 /255？**

实验全息图的 8-bit 值就是相机直接采集的原始灰度值（ADU），不需要恢复到某个"归一化区间"——它们本身就是正确的物理量。`/255` 反而会把值缩小 255 倍，导致重建振幅数量级错误。

**为什么不 -mean()？**

实验全息图的 DC 分量是真实存在的——它是参考光本身。在实验中参考光远强于物光，DC 大是正常物理现象。去掉 DC 反而会改变干涉条纹的物理含义。

### 3.2 对比度反转

```matlab
% 实验模式：invertContrast = true
sliceMax = max(max(Amp, [], 1), [], 2)
I = bsxfun(@minus, sliceMax, Amp)       % ★ max(Amp) - Amp
```

**为什么要反转？**

在真实的同轴数字全息中，粒子表现为局部衍射源。重建振幅中，粒子对应的区域由于干涉相消表现为暗区，而背景是亮的（主要是参考光）。`max(Amp) - Amp` 把暗区（粒子）反转为亮区，方便后续的 MIP 和候选检测。

仿真模式不做反转的原因见 2.2.4 节。

### 3.3 候选筛选参数差异

```matlab
% 实验模式
keep = (diams >= 20) & (diams <= 35)     % ★ 仅接受 20-35px
     & (circularity > 0.6)               % ★ 圆度 > 0.6
```

**粒径 20-35px 的物理含义**（通常 1.0µm/px 像元）：

| | 最小 (20px) | 最大 (35px) |
|---|---|---|
| 像素 | 20 px | 35 px |
| 物理尺寸 | ~20 µm | ~35 µm |

这个范围是根据**已知实验喷雾粒径**设定的——实验喷雾产生的液滴直径通常在 20-35µm 范围内。任何等效直径在此之外的区域（噪声碎片、大块背景不均匀）都被判定为假阳性。

**圆度 > 0.6**：实验中的真实液滴在 MIP 上是近乎完美的圆形投影。0.6 的阈值能排除噪声产生的细长伪影，同时留有一定容错空间。

### 3.4 分水岭参数差异

```matlab
% 实验模式：watershedHmin = 0.8
mask = imextendedmin(D, 0.8)
```

实验全息图噪声更高、MIP 背景不均匀。较高的 H-minima 值 (0.8) 只保留深度 ≥ 0.8 的"明确"极小值，避免将随机噪声波动误识别为粒子间的分界。

## 4. 两条链路参数对照表

| 参数 | 仿真模式 | 实验模式 | 说明 |
|---|---|---|---|
| **预处理：/255** | ✅ `holo/255` | ❌ 不除 | 恢复 BMP 量化损失 |
| **预处理：-DC** | ✅ `holo-mean` | ❌ 不去 | 消除 Python uint8 编码的 DC 偏置 |
| **invertContrast** | `false` | `true` | 仿真粒子是亮区，实验粒子是暗区 |
| **minDiamPx** | **3** | **20** | 仿真粒子可从 ~6.6µm 起；实验仅跟踪 20µm+ |
| **maxDiamPx** | **200** | **35** | 仿真大粒子可达 ~440µm；实验 ≤ 35µm |
| **minCircularity** | **0.3** | **0.6** | 仿真 MIP 粒子投影可能不规则；实验液滴近圆 |
| **watershedHmin** | **0.3** | **0.8** | 仿真噪声低可用浅凹陷分离；实验需避免噪声过分割 |
| **minPeakRatio** | 1.15 | 1.15 | 一致：粒子需有足够信噪比 |
| **edgeMargin** | 2 | 2 | 一致：距 Z 边界至少 2 层 |
| **xyThreshold** | 0.70 | 0.70 | 一致：MIP 前 30% 为候选（可由 GUI 调整） |
| **roiScale** | 0.50 | 0.50 | 一致：初始搜索半径 = 等效直径 × 0.5 |
| **roiMinRadius** | 15 | 15 | 一致：搜索窗口最小半径 15px |
| **measureRoiEnergyFraction** | 0.92 | 0.92 | 一致：92% 能量半径 |

## 6. GUI 复选框如何切换

`VolumeGUI_AngularSpectrum.m` 左栏有一个「Simulation mode」复选框：

```
GUI 布局：
┌──────────────┐
│  左列 (18%)  │
│ ───────────  │
│ [重建参数]   │
│ ☑ Simulation mode   ← 第 197-203 行创建
│ ☐ GPU 加速   │
│ z 最小值     │
│ ...          │
└──────────────┘
```

**复选框的传递链**：

```matlab
% onReconstruct 回调中：
simulationMode = logical(get(handles.hSimulationMode, 'Value'))

% ① 传入预处理函数
prepOpts.isSimulation = simulationMode
holoPre = AS_preprocessHologram(dataImg, bgImg, prepOpts)

% ② 传入快速统计参数
fastStatsParams.simulationMode = simulationMode

% ③ Fresnel_reconstructFastStats 内部：
%    iFillDefaultParams 根据 simulationMode 设置两套默认值
%    → minDiamPx, maxDiamPx, minCircularity, invertContrast, watershedHmin
```

**设计原则**：

- ☑ 勾选 → 走仿真链路 → 所有参数使用仿真默认值
- ☐ 不勾选 → 走实验链路 → 100% 保持原有行为不变

两种模式**互不干扰**，切换只需点一下复选框，无需手动修改任何参数。

## 7. 为什么仿真链路需要这些改动

| 问题 | 根因 | 仿真链路的解决方式 |
|---|---|---|
| **P1**: 20-35px 粒径筛选 | 实验仅跟踪特定喷雾液滴 | 放宽到 3-200px，覆盖所有仿真粒子 |
| **P2**: uint8 直当复数场 | Python `_to_uint8` 非线性压缩 | `/255` 恢复到 [0,1] 浮点域 |
| **P3**: 对比度反转不匹配 | Born 近似粒子是亮区，实验是暗区 | `invertContrast=false`，直接使用振幅 |
| **P4**: 角谱 vs 菲涅尔差异 | 两端使用不同传播模型 | 影响较小（傍轴近似对仿真 f/λ 范围够用） |
| **P5**: Born 近似 vs 实验特征差异 | 仿真无多次散射、无散斑 | 降低分水岭深度 (0.3) + 放宽圆度 (0.3) |
| **DC 偏置** | uint8 编码引入 ~0.5 直流偏置 | 减均值消除 FFT 零频尖峰 |
